# GestureSynthTouch

A gesture synth with cool TouchDesigner-esque effects.

## Credits

Built on top of two lovely projects:

- **[Gesture Synth](https://gesture-synth-weld.vercel.app/)** by [Eric Wei](https://indecisiveeric.com) — the original
  webcam gesture synth this project adapts: the hand-tracking gesture
  mappings, chord system, and synth engine all started as his work. 
- **[finger-frame-effect-lucy](https://github.com/sophiamyang/finger-frame-effect-lucy)**
  by Sophia Yang — the reference for the realtime AI video effect
  (Decart Lucy) that inspired this project's fingertip-hull anime morph.
